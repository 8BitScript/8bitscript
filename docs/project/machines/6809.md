# Writing 6809 support for 8BitScript

This file is for anyone — human or agent — touching the future 6809
backend the roadmap's phase 9 asks for, and the two machines it opens:
the TRS-80 Color Computer (`coco`) and the Vectrex (`vectrex`). Nothing
here builds. Read [`docs/roadmap.md`](../../roadmap.md) first.

> **One 8-bit CPU, two machines that share nothing else. The Color
> Computer is a raster computer. The Vectrex draws vectors. Model the
> CPU once and the display twice.**

The 6809 has 16-bit index registers and an 8-bit data path. That is the
same class of processor as the 6502, which is why phase 9 is on the
roadmap and the Intellivision's 16-bit CP1610 is not
([roadmap](../../roadmap.md#what-counts-as-a-target)). A Motorola
datasheet has not been read for this note; the data-path claim is *to
verify* against that datasheet before a backend is written. What was
read is below.

## What exists today

Nothing. There is no 6809 backend, no `packages/coco`, no
`packages/vectrex`, no emulator flag, and no setup command.

## Facts read for this note

Wikipedia's
[TRS-80 Color Computer](https://en.wikipedia.org/wiki/TRS-80_Color_Computer)
article, fetched 2026-09-22. Secondary; a Tandy service manual is the
source to read next.

| Fact | Where |
| ---- | ----- |
| The Color Computer is a different machine from the Z80 TRS-80. Its CPU is the Motorola 6809E. | Wikipedia, lead |
| CoCo 1: 6809E at 0.895 / 1.79 MHz, MC6847 video display generator, MC6883 SAM. | Wikipedia infobox and the chip list |
| CoCo 2: 6809E at 0.895 MHz, same 6847 generation. | Wikipedia infobox |
| CoCo 3: 6809E at 0.895 MHz by default, software-selectable 1.79 MHz. The GIME chip replaces the 6847 and the SAM, and pages the 64 KB address space as 8 × 8 KB. | Wikipedia, CoCo 3 section |
| The Dragon 32/64 is the same Motorola reference design (6809E, 6847, 6883). | Wikipedia, Dragon section |

The Dragon is not a separate target. CoCo 1/2 versus CoCo 3 is a
hardware axis on `coco` (6847 versus GIME), the same way a PET model is
an axis, and it is not researched past the sentences above.

The Vectrex museum's specification list
([vectrexsystem.html](https://www.vectrexmuseum.com/vectrexsystem.html)),
as returned 2026-09-22, names a Motorola 68A09 at 1.5 MHz, 1 KB of RAM,
an 8 KB system ROM, and a vector display, with a GI AY-3-8912 for sound
and controller I/O. Beam timing, the integrator, and the BIOS calls are
*to verify*. The museum page is not a datasheet.

## The sixteen questions

Answered here: which CPU, and that the two displays are different kinds
of hardware. Memory maps, text, color, sprites (the Vectrex has none in
the raster sense), audio register maps, input, storage, frame timing,
emulators, and the traps are not researched.
