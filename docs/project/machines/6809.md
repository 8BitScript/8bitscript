# Writing 6809 support for 8BitScript

This file is for anyone — human or agent — touching the 6809 backend
(`packages/compiler/src/m6809`) and the two machines on it: `coco` and
`vectrex`.

> **One 8-bit CPU, two machines that share nothing else.** The Color
> Computer is a raster computer (6847 or GIME). The Vectrex draws
> vectors through a 6522 VIA and BIOS calls.

## What exists today

A 6809 backend lowers the same IR the MOS backend sees onto 6809
opcodes. `packages/coco` and `packages/vectrex` ship catalogs, images,
and skip-if-missing emulator tests.

## Facts verified here

| Fact | Where |
| ---- | ----- |
| 6809: two 8-bit accumulators A/B (D = A\|B), X/Y index, S/U stacks, direct-page register, 8×8 unsigned MUL. 8-bit data path. | [MC6809 Preliminary Programming Manual](https://colorcomputerarchive.com/repo/Documents/Manuals/Programming/MC6809%20Preliminary%20Programming%20Manual%20(Motorola).pdf) |
| CoCo 1/2: 6809E at 0.895 / 1.79 MHz, MC6847 VDG, MC6883 SAM. CoCo 3: GIME replaces both and pages 64 KB as 8 × 8 KB. Dragon 32/64 is the same Motorola reference design — a `coco` catalog model, not a target. | Wikipedia *TRS-80 Color Computer*, checked 2026-09-22; catalog `model` |
| Vectrex: 68A09 at 1.5 MHz, 1 KB RAM at `$C800–$CFFF` (shadowed), VIA `$D000–$D7FF` (shadowed 128 times), BIOS ROM `$E000–$FFFF`, cart `$0000–$7FFF`. | [playvectrex memory map](https://www.playvectrex.com/designit/chrissalo/memorymap.htm) |
| Vectrex VIA: ORB `$D000` (MUX, ramp, sound), ORA `$D001` (DAC), T1 `$D004–$D007`, shift `$D00A` (beam blank), ACR `$D00B`, PCR `$D00C`. | [Vectrex 6522 notes](https://roadsidethoughts.com/vectrex/vectrex-6522-interface-adapter.htm) |
| Vectrex BIOS `Wait_Recal` `$F2EB` waits and recalibrates the beam every frame. AY-3-8912 via the VIA. | [Retro Game Coders Vectrex](https://docs.retrogamecoders.com/platforms/vectrex/) |
| Emulators: XRoar (`xroar`) for CoCo; `vecx` or MAME `vectrex`. | Packaged on brew / apt / AUR where available |

## The sixteen questions

Answered for the CPU in the 6809 manual row, for CoCo in the model
option, and for Vectrex in the memory-map / VIA / BIOS rows. Text on
the CoCo is the 6847's 32×16 (or GIME 80×24). The Vectrex has no
character grid — `text` is a stub so portable programs still link.
