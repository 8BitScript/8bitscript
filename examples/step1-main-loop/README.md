# step1-main-loop

Step 1 of the Learn 8BitScript series: the main file, `main()`, and the
`while (true)` loop that keeps a program on the screen.

The walkthrough for this project is
[docs/learn/step1-main-loop.md](../../docs/learn/step1-main-loop.md); the
series index is [docs/learn/index.md](../../docs/learn/index.md).

```bash
pnpm start            # VIC-20, NTSC
pnpm run start:c64    # C64, NTSC
```

`start:pal` and `start:c64-pal` run the PAL models; `build`, `build:c64`,
and their `:pal` variants compile to `dist/` without opening the emulator.
