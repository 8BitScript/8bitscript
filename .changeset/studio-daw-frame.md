Studio opens into the DAW module: a solid menu bar and status bar on every release target, built on a shell that later modules plug into.

The browser page also draws the fluid host at a whole number of device pixels, so its text stays crisp. **Open Studio now runs the modern responsive web build** (`8bs run web`) in the editor tab, so the grid follows the tab. **Open Studio on the X16 (WebAssembly)** is the new command for our Commander X16 model in the tab; the native emulator and x16emu commands are unchanged. The bars are sample text only: nothing opens or plays yet.
