The launcher's Project picker is there whenever the workspace has more than one project. A project with a single program (2048) showed only its name, with no way to switch. In a single-program project the name is now the picker. The menu folds Examples and a new "8BitScript repository" group (the toolchain's own test programs, such as `conform`) until opened, gets a filter once it lists eight or more projects, and shows where each project lives. The Examples toggle hides the repository's own examples too.
