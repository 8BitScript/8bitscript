# Writing Commodore Plus/4 support

This file is for anyone — human or agent — touching `packages/plus4`.
Read the root `AGENTS.md` first.

> **Commodore Plus/4 is its own machine.** Do not translate register numbers
> from the C64, NES, or any other package. Facts come from this catalog
> and from the research page, not from a sibling target.

CPU family: **mos**. Image: `.prg`.
Emulator: `xplus4` (vice).
