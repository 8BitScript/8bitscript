# Writing Tandy Color Computer support

This file is for anyone — human or agent — touching `packages/coco`.
Read the root `AGENTS.md` first.

> **Tandy Color Computer is its own machine.** Do not translate register numbers
> from the C64, NES, or any other package. Facts come from this catalog
> and from the research page, not from a sibling target.

CPU family: **m6809**. Image: `.bin`.
Emulator: `xroar` (dedicated).
