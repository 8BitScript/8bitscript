# Writing Game Boy Color support

This file is for anyone — human or agent — touching `packages/gbc`.
Read the root `AGENTS.md` first.

> **Game Boy Color is its own machine.** Do not translate register numbers
> from the C64, NES, or any other package. Facts come from this catalog
> and from the research page, not from a sibling target.

CPU family: **sm83**. Image: `.gbc`.
Emulator: `sameboy` (dedicated).
