# Writing Atari 5200 support

This file is for anyone — human or agent — touching `packages/atari5200`.
Read the root `AGENTS.md` first.

> **Atari 5200 is its own machine.** Do not translate register numbers
> from the C64, NES, or any other package. Facts come from this catalog
> and from the research page, not from a sibling target.

CPU family: **mos**. Image: `.bin`.
Emulator: `atari800` (atari800).
