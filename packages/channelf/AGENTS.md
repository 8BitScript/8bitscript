# Writing Fairchild Channel F support

This file is for anyone — human or agent — touching `packages/channelf`.
Read the root `AGENTS.md` first.

> **Fairchild Channel F is its own machine.** Do not translate register numbers
> from the C64, NES, or any other package. Facts come from this catalog
> and from the research page, not from a sibling target.

CPU family: **f8**. Image: `.bin`.
Emulator: `mame` (mame).
