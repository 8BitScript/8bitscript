# Writing Atari 2600 support

This file is for anyone — human or agent — touching `packages/atari2600`.
Read the root `AGENTS.md` first.

> **Atari 2600 is its own machine.** Do not translate register numbers
> from the C64, NES, or any other package. Facts come from this catalog
> and from the research page, not from a sibling target.

CPU family: **mos**. Image: `.a26`.
Emulator: `stella` (dedicated).
