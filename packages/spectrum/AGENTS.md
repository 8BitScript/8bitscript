# Writing ZX Spectrum support

This file is for anyone — human or agent — touching `packages/spectrum`.
Read the root `AGENTS.md` first.

> **ZX Spectrum is its own machine.** Do not translate register numbers
> from the C64, NES, or any other package. Facts come from this catalog
> and from the research page, not from a sibling target.

CPU family: **z80**. Image: `.tap`.
Emulator: `fuse` (dedicated).
