# Writing Atari Lynx support

This file is for anyone — human or agent — touching `packages/lynx`.
Read the root `AGENTS.md` first.

> **Atari Lynx is its own machine.** Do not translate register numbers
> from the C64, NES, or any other package. Facts come from this catalog
> and from the research page, not from a sibling target.

CPU family: **mos**. Image: `.lnx`.
Emulator: `mame` (mame).
