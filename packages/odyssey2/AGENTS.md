# Writing Magnavox Odyssey² support

This file is for anyone — human or agent — touching `packages/odyssey2`.
Read the root `AGENTS.md` first.

> **Magnavox Odyssey² is its own machine.** Do not translate register numbers
> from the C64, NES, or any other package. Facts come from this catalog
> and from the research page, not from a sibling target.

CPU family: **i8048**. Image: `.bin`.
Emulator: `mame` (mame).
