# Writing Sega Master System support

This file is for anyone — human or agent — touching `packages/sms`.
Read the root `AGENTS.md` first.

> **Sega Master System is its own machine.** Do not translate register numbers
> from the C64, NES, or any other package. Facts come from this catalog
> and from the research page, not from a sibling target.

CPU family: **z80**. Image: `.sms`.
Emulator: `mednafen` (dedicated).
