# Writing Atari 7800 support

This file is for anyone — human or agent — touching `packages/atari7800`.
Read the root `AGENTS.md` first.

> **Atari 7800 is its own machine.** Do not translate register numbers
> from the C64, NES, or any other package. Facts come from this catalog
> and from the research page, not from a sibling target.

CPU family: **mos**. Image: `.a78`.
Emulator: `mame` (mame).
