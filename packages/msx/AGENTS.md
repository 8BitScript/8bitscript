# Writing MSX support

This file is for anyone — human or agent — touching `packages/msx`.
Read the root `AGENTS.md` first.

> **MSX is its own machine.** Do not translate register numbers
> from the C64, NES, or any other package. Facts come from this catalog
> and from the research page, not from a sibling target.

CPU family: **z80**. Image: `.rom`.
Emulator: `openmsx` (dedicated).
